# electrode

Interactive AR experience for a 4-Pole Contactor and Breaker built with Unity AR Foundation and URP.

## Features
- **Physical Lever Control**: Calibrated pivot lever rotation (-15.4° OFF to 75.0° ON / TRIP) with touch drag and audio feedback.
- **AR Manipulation**: 1-finger translation, 2-finger twist rotation, and pinch-to-scale.
- **Coordinate Pinning / Hanging**: Precision placement at custom world coordinates.
- **Dynamic 3D Wiring**: Cylindrical wires with spherical snap connectors that magnetically attach to 8 input/output terminals.
- **4-Pole Power Simulation**: Live 230V/400V circuit simulation, overload trip logic, and URP emission glow effects.
- **AR UI HUD**: Complete on-screen controls for Breaker state, Mains toggle, and wire spawning.
